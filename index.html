Antivirus Troubleshooting

Windows Defender & Antivirus False Positives

🛡️

Why Defender Flags New Executables

Because newly compiled .exe files are created on your machine and have not yet built up Microsoft SmartScreen cloud reputation or acquired an expensive EV Code Signing Certificate, Windows Defender may classify them as a false positive (e.g. Trojan:Win32/Wacatac!ml where !ml stands for Machine Learning heuristic). Follow these instructions to allow execution:

1

SmartScreen Prompt

When the blue "Windows protected your PC" dialog appears:

  1. Click More info.
  2. Click Run anyway at the bottom.
2

Allow in Windows Security

If Defender quarantined the executable:

  1. Open Windows Security.
  2. Click Virus & threat protection.
  3. Click Protection history.
  4. Select the blocked item → click Actions → Allow on device.
3

Development Folder Exclusion

Prevent Defender from scanning your compilation or output folder:

  1. Go to Virus & threat protection settings → Manage settings.
  2. Click Exclusions → Add an exclusion → Folder.
Add-MpPreference -ExclusionPath "C:\YourBuildFolder"
